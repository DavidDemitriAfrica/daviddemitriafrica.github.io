Projects

Things I've made outside of papers. Each has a site you can explore, and the code for all of them is on GitHub.

Vibecoded Projects

  • Batas

    Every Philippine Republic Act since 1946, sorted by subject and mapped. Six in ten laws concern a single place, most often a school. The site checks whether the schools and hospitals the laws name exist, and measures how much of the Senate's floor time each kind of law takes.

    Site · Code and data

  • Philippine Internal Migration Dataset

    Estimates of how many people moved into and out of every city and municipality in the Philippines, built from PSA censuses, birth and death registration and the PSGC. Every number can be traced back to the file it came from.

    Site · Code and data

  • Street rank

    How structured is your city? Each city's central streets are drawn in the same 5 km square, and the number of stripe patterns needed to rebuild the plan gives its effective rank. A grid needs few patterns and an irregular plan needs many.

    Site · Code and data

  • He Who Saw the Diff

    The Epic of Gilgamesh as a version history. You can diff the Sumerian poems, the Old Babylonian epic and the Standard Babylonian edition against each other, read the text with the other witnesses filling each gap, and see every surviving clay fragment on a map.

    Site · Code

  • Board Game Solutions

    Exact and approximate solvers for recently released board games. You can play Circle the Wagons in the browser against the solver's AI.

    Play · Code
